# What Is an Agent?

An agent is a system that can do a task automatically by following instructions and making decisions along the way.

In simple words, an agent is an automated system that takes an input, processes it, and performs an action to achieve a particular goal.

Unlike a basic program that follows the same steps every time, an agent can decide what to do next based on the situation.

Key Components of an Agent
Input – The information or instruction given to the agent.
Reasoning – The process of understanding the input and deciding what to do.
Tools – Things the agent can use, such as search, databases, APIs, or code.
Action – The task the agent performs.
Output – The final result produced by the agent.
Simple Example

Suppose you ask an AI agent:

"Find the cheapest flight from Delhi to Mumbai for tomorrow."

A basic AI system might simply tell you how to search for flights. An agent could instead:

Understand the destination and date.
Search available flight information.
Compare prices and timings.
Select suitable options.
Present the results.

The main idea is simple: an agent doesn't just give an answer; it can also take steps and perform a task.

# How to Write a Good Prompt: How Input Influences Output

A prompt is simply the instruction or question you give to an AI system.

The way you write the prompt affects the answer you get. A vague prompt may give you a general answer, while a clear and detailed prompt usually gives a more useful answer.

Example

Poor Prompt

Explain statistics.

This is too broad. The AI does not know what part of statistics you want or how detailed the answer should be.

Better Prompt

Explain hypothesis testing for a first-year statistics student.
Include the meaning of null and alternative hypotheses,
p-value, significance level, and one simple numerical example.

This gives the AI more information, so the response can be more focused.

What Makes a Good Prompt?
1. Be Clear

Say exactly what you want.

Summarize this article in 200 words.
2. Give Context

Tell the AI who you are or what you need it for.

I am a first-year statistics student. Explain regression
using a simple real-world example.
3. Tell It How You Want the Answer

You can ask for a specific format:

Explain the topic using:
1. Definition
2. Key concepts
3. Example
4. Summary
4. Mention the Level of Detail

For example:

Explain Bayes' theorem at a beginner level.

# How Input Influences Output

The same topic can produce very different answers depending on the prompt.

Tell me about Python.

This will probably give a general explanation.

But:

I am a BSc Statistics student. Explain how Python
can be used for data analysis and include NumPy,
Pandas, Matplotlib, and one simple example.

This gives the AI a clearer idea of what you need, your level, and how you want the answer.

Key Takeaway

Clearer input → More relevant output

A good prompt usually includes:

Task + Context + Requirements + Desired Format

Good prompting is simply about telling the AI clearly what you want
